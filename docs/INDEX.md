## 🛠️ 技术栈总览

### 核心框架
- **Python 3.10+**: 主要开发语言
- **LangChain/LangGraph**: LLM应用框架
- **ChromaDB**: 向量数据库
- **Redis**: 缓存服务

### LLM支持
- **OpenAI**: GPT系列模型
- **Anthropic**: Claude系列模型  
- **Google**: Gemini系列模型
- **Ollama**: 本地模型部署

### 数据源
- **YFinance**: 股票和技术数据
- **Alpha Vantage**: 基本面和新闻数据
- **Google News**: 新闻数据源
- **本地缓存**: 性能优化

### 部署平台
- **Docker**: 容器化
- **Kubernetes**: 容器编排
- **AWS**: 云服务
- **GCP**: 云服务
- **Azure**: 云服务

### 监控工具
- **Prometheus**: 指标监控
- **Grafana**: 可视化
- **ELK Stack**: 日志管理
